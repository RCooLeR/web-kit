# @rcooler/format

Durations, calendar dates, instants in an explicit time zone (default `Europe/Kyiv`), elapsed time,
numbers, and UAH, USD and EUR amounts. Nothing reads the machine's time zone or language: the zone,
the locale and "now" are arguments, so output is the same on every machine. No runtime dependencies.

```sh
npm install @rcooler/format
```

ESM with type declarations. Part of [web-kit](https://github.com/RCooLeR/web-kit): the
[README](https://github.com/RCooLeR/web-kit#readme) there describes every package, and the
[changelog](https://github.com/RCooLeR/web-kit/blob/main/CHANGELOG.md) lists the changes.
