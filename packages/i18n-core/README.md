# @rcooler/i18n-core

Typed `uk` and `en` dictionaries, placeholders, plural forms and error text by code
(`createTranslator`, `fill`, `toLocale`, `errorCode`). No runtime dependencies. React apps use it
through [`@rcooler/react-i18n`](https://www.npmjs.com/package/@rcooler/react-i18n).

```sh
npm install @rcooler/i18n-core
```

ESM with type declarations. Part of [web-kit](https://github.com/RCooLeR/web-kit): the
[README](https://github.com/RCooLeR/web-kit#readme) there describes every package, and the
[changelog](https://github.com/RCooLeR/web-kit/blob/main/CHANGELOG.md) lists the changes.
